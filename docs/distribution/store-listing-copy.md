# Distribution Copy: Sky Of Many Lanterns

## Product Name
Sky of Many Lanterns

## Short Description
A calm logic adventure for ages 8-10 with grounded hints, short expeditions, and visible parent progress.

## Long Description
Sky of Many Lanterns is a mobile-first logic-learning game for children ages 8-10 and their parents.

Children step into a warm sky world where restoring lantern routes means solving short logic missions across five reasoning skills:
- classification
- patterns
- if / then reasoning
- contradiction spotting
- simple deduction

The experience is built to feel like a real adventure, not a worksheet app. Sessions stay short, hints stay grounded, explanations stay age-appropriate, and the parent dashboard shows concrete progress instead of vague gamified scores.

For fast evaluation, the game also includes an instant-play demo household. That means a parent, reviewer, or partner can feel the product in seconds before deciding whether to run a full setup flow.

## Feature Bullets
- Instant-play demo with no signup wall
- Parent-managed household setup
- Warm, game-like daily expeditions
- Grounded hints and source-traceable explanations
- Parent progress dashboard with strongest skill and current struggle
- Mobile-first web app that runs directly in the browser

## Trust Copy

- Grounded explanations with source traces
- Short, calm sessions designed for repeat return
