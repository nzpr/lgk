# Contractor Package

This directory is the self-contained handoff package for an external contractor CEO.

If the contractor asks "what are the inputs?", the answer is:
- the full book corpus and manifests
- the product and game design documents
- the detailed product description in this package

It is not just a pile of books.
It is a product-description package.

## Folder Map
- `detailed-product-description.md`
  The main contractor-facing product description.
- `deployment-and-acceptance.md`
  The production-ready end state, deployment expectations, and validation checks.
- `01-handoff`
  Contractor-facing summary, detailed goal, input specification, and knowledge inventory.
- `02-product-docs`
  PRD, user flows, game direction, and game systems.
- `04-input-corpus`
  Full corpus files, manifests, and corpus notes.

## Recommended Order
1. Read `detailed-product-description.md`.
2. Read `deployment-and-acceptance.md`.
3. Read `01-handoff/README.md`.
4. Read `01-handoff/detailed-goal.md`.
5. Read `01-handoff/input-specification.md`.
6. Review `02-product-docs`.
